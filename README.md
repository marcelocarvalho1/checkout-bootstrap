# Formulário de Checkout
Um formulário de checkout responsivo desenvolvido com HTML e Bootstrap, projetado para capturar informações de cobrança e facilitar a finalização de compras.

## Descrição
Este projeto apresenta um **Formulário de Checkout** que utiliza controles de formulário do Bootstrap para validar entradas do usuário. O formulário inclui campos obrigatórios que ativam mensagens de erro caso não sejam preenchidos, garantindo uma experiência de usuário fluida e sem erros.

## Tecnologias Utilizadas
- **HTML5**: Estrutura do documento.
- **Bootstrap 5**: Estilos e componentes responsivos.
- **JavaScript**: Validação de formulários.
